# Data

The original vibration dataset is not included in this public portfolio repository.

The team project used four 3-axis accelerometer positions:

- **Xa** — horizontal motion, motor side
- **Xb** — horizontal motion, idler side
- **Ya** — vertical motion, motor side
- **Yb** — vertical motion, idler side

Because the source data were provided for coursework / project use and are not intended for public redistribution, this repository only documents the data structure at a high level.

If a public sample dataset becomes available later, it can be placed in this folder together with a data dictionary.
