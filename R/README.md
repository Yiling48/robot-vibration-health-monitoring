# R Analysis Code

This folder is reserved for reusable analysis functions from the project, such as signal preprocessing, FFT transformation, segmented peak extraction, model training, and cross-validation.

The currently available files shared for this portfolio only include the R Shiny dashboard prototypes, which are stored under `app/`.

To avoid overstating individual ownership in a team project, team analysis code will only be added here when the source files and reuse rights are confirmed.
